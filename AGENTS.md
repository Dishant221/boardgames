# Agent Instructions

Read these two files before doing any non-trivial work in this repo:

- **`INSTRUCTIONS.md`** — the full product spec and target architecture: tech stack, game rules, security requirements, Cloudflare service usage, deployment pipeline, database schema. This is the *intended* end state, not necessarily the current state.
- **`BACKLOG.md`** — what's actually built vs. still pending, kept up to date as work happens. Check here first to avoid re-implementing something that's already done, or assuming something works that doesn't (e.g. the Monopoly game itself is not playable yet — only lobby/session management exists).

When you finish a chunk of work that changes what's built vs. pending, update `BACKLOG.md` to match reality before moving on.
